# Scarp v0.0.6-alpha.8 — prerelease

## Projects and tests

- Initialize offline applications with `scarp init`. Use `scarp run` to execute
  the entrypoint, `scarp verify` to check it statically, and `scarp project info`
  to inspect metadata from the declarative `scarp.project` manifest.
- Run immediate `tests/*.srp` programs with `scarp test`. List tests without
  executing them, request JSON reports, filter by a literal filename substring,
  and use `--require-tests` when CI must discover at least one test.
- Supply a test's UTF-8 input in a sibling `.stdin` file. Every test gets its own
  input and keeps its program output separate from the suite report.
- Check Boolean conditions with `assert(condition, "message");`. A false
  condition reports source-located `E0065`. The optional message is a literal
  of up to 256 UTF-8 bytes.

## Compatibility and limits

Legacy `Scarp.project` projects and the `create`, `launch`, and standalone
`exec` commands remain supported. Rename any existing identifier spelled
`assert`. Rust embedders with exhaustive matches on `Statement` or
`DiagnosticKind` must add the `Assert` or `AssertionFailure` arm, respectively.

Discovery is nonrecursive and limited to 64 immediate test files. A missing or
empty `tests/` directory reports zero tests, and `--require-tests` makes it fail.
Assertions are available in the interpreter and are rejected by the experimental
native backends. The manifest's empty dependency block reserves syntax for
future use. The bundled `examples/projects/calculator` shows the full workflow.
