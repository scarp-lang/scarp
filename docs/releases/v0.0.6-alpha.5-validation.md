## Published scope and exclusions

This alpha.5 adds deterministic, **not stochastic**, `top_p` and
`top_p_values`; finite centered `pearson_correlation`; and bounded dependent
integer bindings in the experimental Rust API
`scarp::native_object::emit_elf64_integer_kernel`. The ELF64 x86-64 output is a
**relocatable object**, not an executable. No general `scarp compile` command,
GPU/tensor runtime, autodifferentiation, package registry, or stable ABI was
published.
