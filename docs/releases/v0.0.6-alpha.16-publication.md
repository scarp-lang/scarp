# Scarp v0.0.6-alpha.16 — prerelease

## Changes

- Adds pure `median(vector)` and `quantile(vector, fraction)` for finite
  vectors, including visible windows. The interpreter charges work and a
  bounded, immutable sorted copy. The bundled `examples/order_statistics.srp`
  demonstrates the behavior.
- Adds live `ConstantCache` retention limits for Rust embedding hosts.
  Reducing the limits evicts oldest entries first while existing compiled
  programs remain usable.
- Probes full stack pages when allocating a large frame for experimental
  Linux x86-64 ELF64 integer kernels. Both kernel return ABIs are preserved.
- Extends deterministic map regression coverage to exact work limits and
  buffered output rollback on both streams.

## Compatibility and limits

The CLI executes through the interpreter. The ELF64 APIs emit a restricted
relocatable integer kernel for Rust hosts. Rust applications with exhaustive
`numeric::Builtin` matches must handle `Median` and `Quantile`.

Public learning and CLI documentation is available in
[English](https://scarp-lang.github.io/scarp-docs/) and
[हिन्दी](https://scarp-lang.github.io/scarp-docs/hi/).
