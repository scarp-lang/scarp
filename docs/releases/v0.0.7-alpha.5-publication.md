# Scarp v0.0.7-alpha.5 — prerelease

- Write shaped float tensors in Scarp source and use checked indexing,
  broadcasting, batched matrix multiplication, reshape, transpose and reductions.
- Differentiate bounded scalar and tensor expressions and train with SGD,
  Adam or AdamW.
- Use explicitly typed signed and unsigned 8-, 16-, 32- and 64-bit integers.
- Emit a standalone Linux x86-64 ELF64 executable for the bounded scalar subset.
- Share immutable tensor views and reuse reverse-mode scratch space across calls.

Run `scarp exec examples/tensor_learning.srp` to see a matrix forward pass,
an automatic gradient, and a weight update.

## Compatibility and limits

Scarp's established integer, float, decimal and BigInt operations keep their
source semantics. The type registry predefines eight additional primitives.
The interpreter supports source tensors and training. The experimental
native executable backend accepts bounded pure scalar functions and rejects
unsupported operations with a diagnostic. Tensor shapes, tapes and optimizer
updates use explicit execution budgets.
