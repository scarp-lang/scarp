## Scope, limitations and post-publication maintenance

This is an experimental, interpreter-backed **prerelease**. The new
dependency impact planner, whole-graph semantic cache, lexical token cache,
parsed AST cache and scoped eviction APIs are opt-in Rust embedding
capabilities. It does **not** ship general Scarp native executable compilation,
a language server, GPU runtime, first-class fixed-size arrays, a package
registry or a stable ABI. Existing C11 scalar output is a restricted
experimental library API.

The one-time `.github/release-request.json` is removed in the
post-publication maintenance PR alongside this record. That retirement does
not move the immutable approved tag, rewrite release notes or archives, or
authorize any future prerelease. The `publish = false` Cargo setting is
unchanged; nothing was published to a crate registry.
