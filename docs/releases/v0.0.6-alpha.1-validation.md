## Post-publication and limitations

Main now lacks the fulfilled `.github/release-request.json` authorization,
so unrelated workflow runs cannot republish this version or automatically
authorize a future release. This record does not move the annotated tag,
replace uploaded assets, change historical tagged source or publish a crate.

The release provides an interpreter-backed experimental language with bounded
symbol/reference navigation and finite root mean square. It does **not** ship
an LSP server, general native executable compiler, tensors, GPU runtime,
package registry or stable ABI. Rust embedding and JSON consumers must use
the versioned navigation contract and rebuild snapshots after edits.
