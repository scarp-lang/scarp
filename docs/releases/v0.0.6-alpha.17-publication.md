# Scarp v0.0.6-alpha.17 — prerelease

## Changes

- `array_len(values)` returns the size of a fixed array for use with `repeat`.
  `array_get_or(values, index, fallback)` returns the fallback for a negative or
  out-of-bounds index. The fallback has the exact element type and evaluates
  once, even when the index is valid. Ordinary indexing still reports E0063.
- `input_boolean(prompt)` accepts the exact lowercase literals `true` and
  `false` when `--interactive` is enabled. A malformed line reports E0084.
  End of input before a new line reports E0055.
- Binding diagnostics preserve focused repair guidance and the source span for
  invalid lengths inside nested fixed-array type annotations.
- Older compiler tutorials link to the official, version-aware Scarp Docs
  guides in English and Hindi.

## Try the bundled examples

```sh
scarp exec examples/array_traversal.srp
scarp exec --interactive --input-file examples/interactive/boolean_prompt.stdin examples/interactive/boolean_prompt.srp
```

## Compatibility and limits

- Native packages are available for Windows x64, Linux x64 and Apple Silicon
  macOS. Source builds support Rust 1.74 or later.
- The array and console additions run in the interpreter. The experimental
  native backend retains its existing scalar scope.
- The downloads include a SHA-256 file for each archive and a combined `SHA256SUMS`.
