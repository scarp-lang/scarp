# Scarp v0.0.6-alpha.5 — prerelease

Scarp's experimental scientific/AI toolset gains deterministic nucleus
selection, centered correlation, and a further narrow compiler-owned
native object-generation milestone.

## New scientific and AI operations

`top_p(probabilities, mass)` returns original zero-based candidate indices
in descending score order, stopping at the first prefix reaching the
requested positive cumulative mass. `top_p_values` returns the scores in
that same stable order. Inputs must be nonempty, finite, nonnegative and
normalized to 1 within the documented tolerance; exactly mass 1.0 retains
all original elements (including zero-probability tails). These functions
are **deterministic ranking**, not random sampling or AI-model execution.

`pearson_correlation(left, right) -> float` measures the *centered*
linear relationship between nonconstant paired finite numerical vectors.
Both axes are independently scaled; large offsets, extreme finite
magnitudes, compensated reductions and fixed work limits are covered by
source tests and runnable examples.

## Verified native object-generation step

The experimental Rust API
`scarp::native_object::emit_elf64_integer_kernel(source)` uses Scarp's
checked frontend and private verified scalar IR. A bounded sequence of
integer `bind` initializers may depend on preceding integer bindings;
the exported `scarp_scalar_kernel() -> i64` returns the last bound value.
It generates an ELF64 x86-64 **relocatable object**, not an executable.
Linux host linking is only a test; Windows and macOS executable generation,
stable FFI/ABI, full arithmetic and `scarp compile` remain unsupported.

## Compatibility, packages and limits

These additions preserve existing interpreter-backed `.srp` source
commands, typed diagnostics, immutable vectors and explicit numerical
resource budgets. Rust embedding users that exhaustively match
`numeric::Builtin` need to add the new variants. The compiler remains
experimental, and GPU, generalized tensors, autodifferentiation,
native executable linking, stochastic sampling, full LSP and package
registry distribution are not added.

GitHub prerelease archives are built for Windows x64, Linux x64 GNU and
macOS Apple Silicon. They include the executable, source documentation,
the `nucleus_selection` and `pearson_correlation` runnable examples
with exact stdout, and checksums. They are not crates.io/npm packages.
The guarded publisher independently verifies tagged source, all
seven CI jobs, SHA-256 sidecars, draft assets and public downloads.
