# Scarp v0.0.6-alpha.14 — prerelease

## Compiler and runtime

- Destructuring diagnostics identify missing or duplicate commas and the
  expected closing delimiter in nested tuple, array and record patterns.
- Source-level regression tests cover nested nominal payloads, immutable
  arm bindings, exact diagnostic spans and deterministic map projections.
- The native verifier rejects repeat operations that use one slot for both
  count and index.

## Rust embedding

- `EditorCompilationCache::set_limits` updates all five retention quotas on
  a live cache. Eviction follows insertion order. Issued programs and editor
  snapshots retain their original data and revisions.
- Cold and warm editor compilation are compared across edits to a shared
  dependency, including navigation, execution, and diagnostic locations.
- `emit_elf64_checked_integer_kernel` supports checked addition, subtraction,
  multiplication, negation, division and remainder in its linear integer
  binding subset. The Linux x86-64 System V result includes a status and a
  UTF-8 operator span on failure. See the [ELF64 ABI](../native-elf64.md).

## Compatibility and limits

Existing source syntax, CLI commands, JSON schemas and the original ELF64
kernel API remain compatible. The checked object emitter is a Rust embedding
API. The Windows x64, Linux x64 and macOS Apple Silicon CLI packages use the
interpreter. Pattern guards and refutable nested patterns are outside this
release's scope.
