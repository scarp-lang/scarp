# Scarp v0.0.6-alpha.13 — prerelease

## New in alpha.13

- Option and Result propagation reuses an existing immutable error payload.
  Forwarding `None` needs no payload allocation.
- Syntax and semantic caches support changing retention limits. The semantic
  cache can evict a specific revision, older revisions, revisions at or above
  a ceiling, or a half-open revision interval for a trusted source identity.
  Returned programs stay valid after eviction.
- Rust editor integrations can bind a static analysis to a workspace generation.
  A host can discard late navigation results and diagnostics after an edit or
  import rebinding, including when individual document revisions match.
- New regression fixtures exercise ordered map projections, allocation
  boundaries, and cache snapshots. Existing Scarp CLI commands and project
  manifests retain their behavior.

## Compatibility and limits

Native packages target Windows x64, Linux x64, and Apple Silicon macOS.
Building from source supports Rust 1.74 and newer. Scarp source programs run
through the interpreter. The cache and editor additions are opt-in Rust
embedding APIs. The host must track workspace generations and document
revisions. Cache quotas measure retained compiler data using logical counts
and byte totals.

The packaged task board demonstrates records, lists, maps, and typed state
transitions. Use `scarp verify`, `scarp launch`, and `scarp test` with
`examples/projects/task-board`.
