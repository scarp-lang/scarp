# Scarp v0.0.6-alpha.20 — prerelease

## Changes

- The experimental Rust embedding API can emit deterministic Linux x86-64
  ELF64 objects for pure Scarp functions with one to six integer parameters.
  It supports integer and Boolean locals, checked arithmetic, local
  assignments, short-circuit logic, and early integer returns.
- Decimal literals such as `0.1d` preserve exact base-ten arithmetic.
  Unsuffixed floating-point literals retain their existing behavior.
- Mutable tuples support persistent replacement at a constant member index.
  Compatible numeric tuples support lexicographic ordering.
- New projects use `scarp.project`. Existing projects with the legacy
  `Scarp.project` filename remain readable.
- Cumulative Rust host argument quotas include strings inside composites.
  Shared strings are counted by logical occurrence.

## Compatibility and limits

The native API targets the Linux x86-64 System V ABI. It keeps the existing
zero-argument symbols and adds `scarp_checked_integer_function` with a fixed
signature per object. Arithmetic failures return a status and source-span
index. The native subset excludes loops, calls, contracts, defaults, and
heap-backed values. Scarp's CLI continues to execute through the interpreter.

Argument admission reports logical UTF-8 bytes. The interpreter's cumulative
quotas and the host's process memory remain distinct measurements.
