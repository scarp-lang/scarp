# Scarp v0.0.6-alpha.9 — prerelease

## Project test reports

Use `scarp test --json=v2` to get a diagnostic object for each failed test.
The report distinguishes compile, fixture, and runtime failures and includes
codes, project-relative source paths, UTF-8 byte spans, and Unicode-scalar
positions when available. Program output and source excerpts stay out of the
report. Explicit diagnostic messages, such as assertion messages, are included.
The original `--json` format, test discovery, filters, and exit codes retain
their existing behavior.

## Exact signed integers

Use `bigint("12345678901234567890")` to construct an exact decimal value and
`bigint_from_integer` or `bigint_to_integer` for explicit conversions.
BigInt supports signed arithmetic, comparison, and use in functions, modules,
and tuples. Division truncates toward zero and the remainder follows the
dividend's sign. See the bundled `docs/bigint.md` and BigInt examples.

## Compatibility and limits

- The existing `integer` type remains signed 64-bit. BigInt uses a default
  limit of 10,000 decimal digits and an 8 MiB cumulative limb budget. The
  configurable ceiling is 1,000,000 digits, subject to work and storage limits.
- Rust hosts with exhaustive `ExecutionOptions` struct literals need
  `max_bigint_digits` and `max_bigint_bytes` or struct update syntax.
  Exhaustive `Value`, `PrimitiveType`, `numeric::Builtin`, and
  `DiagnosticKind` matches need the new variants.
- Packages target Windows x64, Linux x64, and macOS Apple Silicon.
  The Rust source requires Rust 1.74 or later.
- BigInt executes in the interpreter. Fixed-size arrays, advanced BigInt
  operations, and a native executable CLI are outside this release scope.
