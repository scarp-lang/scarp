# Scarp v0.0.7-alpha.2 — prerelease

## Changes

- Compile pure integer functions to x86-64 ELF64 objects with the new
  experimental `scarp native-object` command. The command requires an explicit
  target and a new output path. It writes the complete object atomically and
  can report ABI details and original source byte ranges as JSON.
- Select an entry function with `bounded-entry` and compile its nonrecursive
  direct calls within the same file. Calls pass up to sixteen integer
  arguments, with six in registers and up to ten on the stack. Work is
  charged across the call graph. The compiler verifies depth and the caller's
  stack budget before emission.
- Keep eligible scalar temporaries in a register and preserve live values
  across calls. Nested errors retain their original status and source span
  through the stack-restoring return path.
- Query checked x86-64 sizes, alignments and offsets for tuples, records,
  fixed arrays, variants, Option and Result through the Rust API.

See the [native object command and examples](https://github.com/scarp-lang/scarp/blob/v0.0.7-alpha.2/docs/native-object-output.md).

## Downloads

The compiler packages target Windows x86-64, Linux x86-64 and macOS Apple
Silicon. Each archive has a SHA-256 sidecar and the release includes
`SHA256SUMS`.

## Compatibility and limits

`scarp exec` uses the interpreter. Generated objects target `x86_64-none`
and use an experimental SysV AMD64 calling convention. Linking and external
calls require additional tooling and design work. Aggregate planning
provides layout data for future code generation. Native recursion, heap-backed
values and aggregate execution remain future work.
