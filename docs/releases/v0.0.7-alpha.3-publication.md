# Scarp v0.0.7-alpha.3 — prerelease

- Generic `funcra` declarations support bounded specialization, explicit type
  arguments, contextual inference, and generic Option and Result payloads.
- The experimental ELF64 integer entry can call concrete integer
  specializations. Constant folding preserves checked errors, source spans,
  and work accounting.
- Bounded native integer functions and entries support flat fixed arrays,
  tuples, and records as stack locals. Array bounds failures report the
  subscript's source span.
- Strings support bounded concatenation and repetition, raw literals, and
  multiline literals.
- Function completion retires unneeded interpreter values and transfers the
  result without duplicating its ownership for contract evaluation.

## Compatibility and limits

The CLI executes Scarp programs through the interpreter. Native output is
experimental x86-64 ELF64 relocatable object code for an external linker.
Aggregates in the native subset are private locals with integer or Boolean
components. The existing integer entry calling convention remains in use.

See [generic functions](../generic-functions.md),
[string operators](../string-operators.md), and
[ELF64 output](../native-elf64.md).
