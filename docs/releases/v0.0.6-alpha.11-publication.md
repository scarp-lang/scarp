# Scarp v0.0.6-alpha.11 — prerelease

## Exact decimal values

Scarp programs can use the experimental `decimal` type for exact base-10
arithmetic. As with other Scarp types, bindings, functions, tuples, fixed
arrays and imported signatures retain their exact type.

```scarp
bind price: decimal = decimal("199.99");
bind tax = decimal("0.18");
print(decimal_format(price + price * tax, 2, "half_even"));
```

This prints `235.99`. Use `decimal_from_integer` and `decimal_to_integer`
for explicit conversions. `decimal_round` changes the value and
`decimal_format` returns text with the requested number of displayed places.
`decimal_div_rounded` accepts an explicit scale and rounding mode for
quotients such as `1/3`.

## Interactive input

`input_decimal(prompt)` reads and validates an exact decimal after flushing
the prompt with `scarp exec --interactive`. Use `--input-file PATH` to replay
the packaged example with its UTF-8 fixture. Redirected noninteractive
programs can use `decimal(read_line())`.

## Compatibility and limits

- Decimal supports up to 28 canonical coefficient digits and 18 fractional
  places. The parser accepts signed ASCII decimal text. It rejects exponents,
  digit separators and implicit conversions to or from `float`.
- Exact division reports an error when its quotient requires rounding. Source
  module constants remain scalar expressions without constructor calls.
  Decimal execution is interpreter-only. The experimental native emitters
  reject it with E0049.
- The new diagnostics are E0068 for text or rounding mode, E0069 for shape or
  input limits and E0070 for inexact operations. Rust embedders with exhaustive
  matches should update for Decimal and the new diagnostics.
- The module inventory retains schemas 1–3. A Decimal signature adds the
  `decimal` type string. Array-bearing signatures still use schema 3.
- Native archives target Windows x64, Linux x64 and macOS Apple Silicon.
  The compiler source supports Rust 1.74 and newer.
