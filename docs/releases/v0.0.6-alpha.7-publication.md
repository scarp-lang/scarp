# Scarp v0.0.6-alpha.7 — prerelease

## New in v0.0.6-alpha.7

- Use `if`/`elif`/`else` as a value in interpreter expressions. Conditions are
  boolean, each branch yields one expression, and all results share an exact
  type. The interpreter evaluates only the selected result.
- Write Unicode scalars in strings as `\u{HEX}` with one to six ASCII hex digits.
  The lexer emits UTF-8 and diagnoses malformed escapes, surrogates and values
  above U+10FFFF.

## Compatibility and limits

Conditional expressions require a final `else`. Use them in interpreter code.
Module constants and the experimental C11 and ELF64 backends reject this form.
Rust embedders with exhaustive matches on `ExpressionKind` need a `Conditional` arm.
