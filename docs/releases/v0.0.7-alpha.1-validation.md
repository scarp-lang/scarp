| Gate | Required evidence |
| --- | --- |
| Rust checks | Stable Linux, Windows and macOS jobs, plus Rust 1.74.0 |
| Native verification | Scalar differential tests and the Linux QEMU smoke workflow |
| Lifetime | Baseline comparison against the PR base and regression tests for return values, errors and buffer retention |
| Windows x86-64 | Extracted executable smoke tests and identical archive hashes after independent Cargo builds |
| Linux x86-64 | Extracted executable smoke tests and identical archive hashes after independent Cargo builds |
| macOS Apple Silicon | Extracted executable smoke tests and identical archive hashes after independent Cargo builds |
| Combined archives | Exact Git source, approved inventory, archive paths and SHA-256 verified in the package workflow |

Run links and artifact digests are recorded against the candidate SHA in the
pull request checks and the final qualification report. CI on an earlier PR
revision cannot qualify the final `main` source.
