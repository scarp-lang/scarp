## Qualification gates

The baseline is the [published v0.0.7-alpha.1 prerelease](v0.0.7-alpha.1-validation.md).
The [public notes](v0.0.7-alpha.2-publication.md) describe the candidate scope.

| Gate | Evidence required on the final source |
| --- | --- |
| Rust checks | Stable Linux, Windows and macOS, plus Rust 1.74.0 |
| Native verification | Independent ELF and C ABI checks, interpreter comparisons, exact stack budgets and a QEMU boot of the CLI-generated call graph |
| Lifetime | Existing interpreter retention tests and native frame cleanup on success and early failure |
| Windows x86-64, Linux x86-64 and macOS Apple Silicon | Extracted executable smoke checks, including the native object command, with two matching clean-build archives per host |
| Combined archives | Three verified archives and checksums matched to the exact Git source |
