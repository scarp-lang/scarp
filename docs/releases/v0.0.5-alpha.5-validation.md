## Post-publication maintenance

The one-time `.github/release-request.json` is removed in the accompanying
maintenance PR to make subsequent publisher runs inert until a new, separately
reviewed exact-source authorization. This documentation change does not alter
the annotated tag, released source, uploaded assets or earlier prereleases.

**Language limitations:** this is an interpreter-backed experimental Scarp
release. The C11 emitter is a deliberately restricted Rust embedding API,
not a `scarp compile` CLI command or a self-hosting native compiler. No crate
was published to a registry (`publish = false`).
