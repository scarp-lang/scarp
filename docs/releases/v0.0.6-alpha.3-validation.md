## Included features, limitations and retirement

- New pure typed AI score helpers:
  `topk`, `topk_values`, `softmax_temp`, and
  `logsoftmax_temp`; all have deterministic resource and numerical contracts,
  examples and source documentation.
- Internal verified scalar expression and statement IR, test-only
  interpreter/IR differential execution, and definite-initialization
  control-flow checks. **No general native object writer, new
  `scarp compile` CLI, GPU/tensor engine, LSP, stable ABI or automatic
  differentiation runtime** is claimed.
- [Draft PR #149](https://github.com/scarp-lang/scarp/pull/149)
  adds future deterministic Top-P candidate selection but is **not in this
  tagged release** and must not be retroactively included.
- The completed one-time `.github/release-request.json` must be **removed**
  in the separate postpublication maintenance PR accompanying this record.
  Its removal never changes the immutable source SHA, tag, public assets,
  or previously published versions. New prereleases require fresh
  exact-source approval and fresh seven-job gates.
- `publish = false` remains unchanged in `Cargo.toml`; this GitHub
  prerelease does **not** publish a crate or npm package.

[Public-facing notes](v0.0.6-alpha.3-publication.md) and
