# Scarp v0.0.6-alpha.5 — proposed release notes

**Versioned development source candidate, NOT a tag or published prerelease.**
This version must not be merged before v0.0.6-alpha.4 is independently
published and its one-time control request is retired, or the maintainer
explicitly changes the planned release sequence.

## Proposed release contents

1. **Top-P nucleus ranking:** `top_p` and `top_p_values` select
   a stable score-ranked minimal probability prefix; deterministic and
   pure, not stochastic model sampling.
2. **Scientific Pearson correlation:** `pearson_correlation` computes
   the centered relationship between nonconstant paired numerical vectors
   using overflow-resistant normalized reductions, finite inputs and
   checked resource budgets.
3. **Experimental native compiler progress:** the narrow Linux x86-64 ELF64
   integer-kernel Rust API now accepts a bounded sequence of integer
   bindings referencing preceding bindings, rather than only a standalone
   initializer. No first-party ELF executable linker, general
   `scarp compile` route, arbitrary arithmetic, output or stable ABI.
4. **Integrated matrix:** require the exact source revision to pass Rust
   1.74, Windows/Linux/macOS, three native archives and byte-exact examples.

## Publication gates

- Merge only individually reviewed and green feature PRs; do not
  merge the integration-only verification PR directly.
- Upgrade `Cargo.toml`, `Cargo.lock`, release metadata, docs,
  compatibility, and package/verification contracts together.
- Verify full final-main four Rust and three package jobs.
- Independently inspect archives, source identities, clean BUILD-INFO,
  all three SHA-256 sidecars, mandatory source/docs/examples, exact
  stdout and combined SHA256SUMS.
- Obtain a *new* explicit maintainer approval naming
  **v0.0.6-alpha.5** and the final source's **complete 40-character SHA**.
- Only then open, review and merge its own one-time control request,
  verify fresh control-revision seven-job matrix, use guarded publisher
  and independently audit seven uploaded public assets.
