## Published scope and remaining limits

This release adds bounded input, text and tuples: explicit read_line readers and
redirected stdin, six scalar/text intrinsics and immutable heterogeneous tuple
values/types/projections across functions and module interfaces. SourceType,
Value::Tuple and complete ExecutionOptions literals require the documented Rust
migration; tuple-exposing module inventories use schema 2. Primitive IDs and
navigation/diagnostic schemas remain compatible.

Interactive prompts, empty tuples, tuple constants, dynamic tuple indices,
destructuring, mutable elements, BigInt, general collections, GPU runtimes and
native tuple/input execution remain excluded. No stable compiler or registry
release was made. External Docs/By Example/Playground/editor adoption is separate.

The fulfilled `.github/release-request.json` is retired with this record.
Future versions require a fresh reviewed source, request and full qualification.
