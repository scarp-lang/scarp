## Release features and precise exclusions

This experimental release adds checked sampled-calculus
`sample_area`, `sample_cumulative_area`, `sample_slopes`,
finite `cosine_similarity`, and the **first one-binding** safe-Rust
x86-64 ELF64 relocatable integer-kernel emitter. Its published
interpreter-backed CLI and language syntax remain unchanged.
It does **not** ship Top-P, Pearson correlation, multi-binding native
kernel dependencies, a general native executable compiler, a public
`scarp compile` CLI, GPU, tensors, autodifferentiation or stable ABI.
Those post-alpha.4 developments require a separately source-pinned
future release.

**One-time request retirement:** the completed
`.github/release-request.json` must be removed by the maintenance PR
containing this record. Retiring it cannot change the immutable approved
source, annotated tag or public uploaded bytes. Any subsequent alpha.5
publication requires its **own** independently authorized full-source SHA,
passing exact-main seven-job gates and new reviewed one-time request.
