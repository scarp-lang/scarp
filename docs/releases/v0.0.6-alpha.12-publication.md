# Scarp v0.0.6-alpha.12 — prerelease

## New in alpha.12

- Typed source records and tagged variants, with nested destructuring and
  checked exhaustive matching. Tuple and fixed-array bindings support
  destructuring without changing their existing value semantics.
- Concrete `option<T>` and `result<T, E>` types, including early return
  through `bind value = expression?;` and canonical identity across modules.
- Immutable typed lists and deterministic maps, with checked operations,
  allocation budgets, and canonically ordered key and value projections.
  Removal copies only the entries retained by the new snapshot.
- A multi-file task board project with typed actions, pure transitions,
  lookup and validation, deterministic output, and automated project tests.

## Compatibility and limits

The interpreter retains exact Decimal semantics and typed console input.
Use `scarp verify`, `scarp launch` and `scarp test` with the example project at
`examples/projects/task-board`. Aggregate operations remain interpreter
features. Experimental native backends support their existing narrower
subsets and reject unsupported aggregate programs. The host-side data
engine from PR #249 and user-defined generics remain outside this scope.

The packages target Windows x64 MSVC, Linux x64 GNU, and Apple Silicon macOS.
Scarp remains experimental. See the accompanying SHA-256 files to verify
downloaded archives.
