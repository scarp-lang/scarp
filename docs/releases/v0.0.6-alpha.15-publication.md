# Scarp v0.0.6-alpha.15 — prerelease

## Compiler and runtime

- `inspect tokens`, `inspect ast` and the legacy `tokens` command read regular
  UTF-8 files up to 1 MiB. Oversized inputs fail before tokenization.
- Equality and inequality on equal-length strings charge one step for each
  started 64 UTF-8 bytes. The charge applies to runtime and constant evaluation,
  with matching results and diagnostics on cold and warm constant compilation.
- The semantic compilation cache checks revisions supplied by the loader
  against the requested values before considering a cached program.

## Experimental ELF64 kernels

The checked x86-64 ELF64 kernel supports `<<`, `>>` and `>>>` with full
count validation. Counts outside 0 through 63 produce status 3 and the first
failing operator's UTF-8 byte span. Both kernel APIs accept a linear sequence
of immutable integer bindings. The encoder applies its machine-code size cap
to emitted bytes.

## Compatibility and limits

Scarp source programs use the same syntax. Equal-length string comparisons can
reach tight work limits earlier. Rust callers matching `CachedCompileError`
exhaustively should handle `RevisionMismatch`, and checked kernel hosts should
recognize `CHECKED_KERNEL_INVALID_SHIFT`. The ELF64 APIs produce relocatable
objects for selected integer kernels. The CLI executes through the interpreter.

Packages target Windows x64, Linux x64 and macOS Apple Silicon.
