# Scarp v0.0.7-alpha.1 — prerelease

This experimental release extends Scarp's systems-programming foundations and
adds bounded interpreter and numerical operations.

## Changes

- The experimental x86-64 ELF64 Rust API supports pure integer functions with
  zero to sixteen required integer arguments, scalar conditional expressions,
  counted repeats, while loops, and nested loop control. The bounded entry API
  meters execution work and retains source byte spans for failures. The object
  writer verifies section ranges and reuses temporary stack slots.
- The interpreter can retire completed ordinary frames and reuse one bounded
  spare set of buffers per execution. Returned immutable values keep their
  references and retain their contents across later calls.
- `array_concat` combines fixed arrays with the same exact element type and
  infers the result length. Fixed arrays remain distinct from numeric vectors.
- `integer_gcd`, its alias `integer_hcf`, and `integer_lcm` accept 2–1024 integer
  arguments. Vector `softplus` computes a stable result across finite inputs.
- Rust hosts can adjust token-cache retention limits in place. The cache
  evicts in insertion order and existing compiled snapshots remain usable.
- `scarp exec` runs the current project with bounded console input. New
  project manifests use `scarp.project`. Legacy `Scarp.project` files remain
  supported.

## Downloads

Package targets are Windows x86-64, Linux x86-64, and macOS Apple Silicon.
Compare the downloaded archive with its SHA-256 file or `SHA256SUMS`.

## Compatibility and limits

Native object emission is experimental and uses the Rust API. The object ABI
is provisional, and `scarp exec` uses the interpreter. General native function
calls, an executable linker, and a native compilation CLI are outside this
release's scope. Lifetime currently covers interpreter scope retirement, frame
reuse and immutable shared storage. Module constants remain scalar.
