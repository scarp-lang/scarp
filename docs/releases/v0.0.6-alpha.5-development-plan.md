`v0.0.6-alpha.4` development source `f04be0758cbce405ddcdb229699b0ff83c09d207`.

## Engineering follow-up candidates (not committed features)

1. **Native compiler**: make binding-slot lifetime/dataflow validation
   resilient under more statement families; propose first runtime error
   status + checked operation ABI before exposing arithmetic and branching.
   Only after independent object/linker differential tests consider
   experimental `compile --emit obj` and non-overwriting output handling.
2. **Language type system**: evaluate immutable fixed-size arrays under
   issue #118 before introducing `record`, `variant` or match keywords.
   New syntax is a design proposal, not a shipped feature.
3. **Scientific/AI correctness**: benchmark new O(N) correlation and O(N log N)
   nucleus kernels with reproducible baselines, expanded extreme numerical
   oracles and stable source-argument diagnostics. No performance claims
   without measured results.
4. **Ecosystem**: update scarp-docs, scarp-by-example, website and VS Code
   feature compatibility *after* verifying the actual compiler source and
   corresponding published version; never advertise a draft as shipped.
