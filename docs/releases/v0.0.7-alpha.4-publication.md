# Scarp v0.0.7-alpha.4 — prerelease

## Native compilation

- The experimental Rust ELF64 entry API supports bounded self and mutual
  recursion with independent work, active-frame and stack limits. Resource
  exhaustion preserves the source span through active frames.
- Bounded native functions and entries accept nested fixed arrays, tuples,
  and records in private frame storage. Each value can contain up to 32
  integer or Boolean leaves. Checked indexing and initializer order match
  the interpreter on the supported subset.
- The public native ABI continues to use integer parameters and the
  checked integer result. Objects target x86-64 ELF64 and can be linked by
  a host. General executable output and aggregate ABI support remain open.

## Generics and exact arithmetic

- A contextual return type can determine the type of an inner generic call
  while other arguments determine the remaining outer type parameters.
- New bounded exact BigInt operations cover number theory, sequences, and
  wide exponents. Decimal output uses bounded chunks. Higher digit limits
  require explicit opt-in budgets. Large-number fixtures verify specific
  operand shapes using an exact byte oracle.
- The experimental `scarp bigint` command performs file-backed addition,
  subtraction, one-limb multiplication, and checked division. Division
  outputs a canonical truncated quotient and a signed remainder. Work,
  buffers and staging storage have explicit limits.

## Compatibility and limits

`scarp exec` remains the interpreter entry point. The compiler packages
target Linux x86-64, Windows x64, and macOS ARM64. Rust 1.74 remains the
minimum supported toolchain.
