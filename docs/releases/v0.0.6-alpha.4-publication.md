# Scarp v0.0.6-alpha.4 — prerelease

This experimental Scarp update expands finite scientific computing and adds a
first small native object-generation milestone without changing the
interpreter-backed CLI.

## New in v0.0.6-alpha.4

**Sampled calculus:** `sample_area(x, y)` computes trapezoidal integration,
`sample_cumulative_area(x, y)` computes each prefix integral, and
`sample_slopes(x, y)` returns secant interval slopes. Inputs must be
equal-length finite vectors with strictly increasing coordinates. Shape,
domain, finite-output and resource budgets are checked.

**Cosine similarity:** `cosine_similarity(left, right) -> float` computes
the similarity of two nonzero equal-length numeric vectors. Independent
scaling and compensated reductions handle finite extremes without allocating
an output numerical vector; windows remain immutable.

**Native object milestone:** `scarp::native_object::emit_elf64_integer_kernel`
provides a compiler-owned x86-64 ELF64 relocatable-object encoder in safe Rust.
It reuses the verified private scalar IR and supports **one pure integer
initializer** using literals, groups and bitwise NOT/AND/OR/XOR. Emission does
not call a C compiler. An independent Linux x86-64 test links and runs the
emitted function.

## Examples and documentation

Archives include `examples/sampled_calculus.srp`,
`examples/sample_cumulative_area.srp`, `examples/cosine_similarity.srp`
and their exact stdout fixtures. Scope and error contracts are in
`docs/sampled-calculus.md`, `docs/cosine-similarity.md` and
`docs/native-elf64.md`.

## Compatibility and limits

The language syntax, source keywords and CLI remain unchanged. New numerical
variants of Rust `numeric::Builtin` require updates to exhaustive host
matches. The ELF kernel API does **not** generate general Scarp executables,
provide a `scarp compile` command or expose a stable runtime ABI.
Arbitrary native arithmetic, native I/O, Windows PE/Mach-O generation,
draft Top-P selection, general arrays, tensors, GPUs, autodifferentiation,
language servers and package registries remain outside this release.

Native compiler/interpreter packages support Windows x64, Linux x64 and
macOS Apple Silicon, with docs and examples. These are GitHub prerelease
archives, not a crates.io/npm publication. Source identity and assets are
independently verified by the guarded release publisher.
