## Proposed release contents

### AI-oriented language features

- **Deterministic Top-K ranking** ([PR #146](https://github.com/scarp-lang/scarp/pull/146)):
  `topk(scores: vector, count: integer) -> integers` returns original indices
  in descending score order, and `topk_values(scores: vector, count: integer)
  -> vector` returns the corresponding scores. Ties choose the earliest
  original index (including signed zeros). The heap is bounded by `count`.
  Zero count and empty vectors are supported; invalid counts fail with E0033.
  See [Top-K guide](../topk-selection.md) and
  [example](../../examples/topk_scores.srp).
- **Temperature-controlled model probabilities**
  ([PR #147](https://github.com/scarp-lang/scarp/pull/147)):
  `softmax_temp(scores: vector, temperature: float) -> vector` and
  `logsoftmax_temp(scores: vector, temperature: float) -> vector`.
  Temperature must be a strictly positive finite float. Maximum-shifted,
  compensated normalization handles large scores without silently returning
  nonfinite vectors. Unrepresentable log probabilities are diagnosed with
  E0031 rather than stored. See
  [temperature guide](../temperature-softmax.md) and
  [example](../../examples/temperature_softmax.srp).

### Private compiler safety (no new user-facing native CLI)

- [PR #141](https://github.com/scarp-lang/scarp/pull/141):
  harden scalar-only backend preflight and independent verification.
- [PR #142](https://github.com/scarp-lang/scarp/pull/142):
  introduce bounded, typed scalar expression IR with forward short-circuit
  branches and source spans.
- [PR #143](https://github.com/scarp-lang/scarp/pull/143):
  add private whole-program scalar statement/control-flow IR.
- [PR #144](https://github.com/scarp-lang/scarp/pull/144):
  add **test-only** IR execution and interpreter differential regressions
  across arithmetic, quotas, Unicode spans, control flow, and failures.
- [PR #145](https://github.com/scarp-lang/scarp/pull/145):
  add fixed-point definite-initialization checks, rejecting reachable reads
  before initialization or after retirement on any possible control-flow path.

The experimental Rust-hosted C11 emitter retains its documented scalar-only
scope. **These changes do not provide** a native object writer, general
`scarp compile` command, GPU kernels, agent runtime, package manager,
language server, tensor engine, general automatic differentiation, or a stable ABI.

## Compatibility and resource contracts

The new pure numerical built-ins preserve existing typed call resolution and
runtime output transactionality. Rust hosts exhaustively matching
`numeric::Builtin` need to handle four new variants. Existing source programs
and the Scarp-first CLI have no intentional syntax or command changes.
Top-K and temperature kernels use deterministic work charges and finite,
bounded vector allocations; see their feature guides for formulas and
diagnostics. Source module caches remain opt-in Rust APIs.

Development examples:
```sh
cargo run --locked -- run examples/topk_scores.srp
cargo run --locked -- run examples/temperature_softmax.srp
```
